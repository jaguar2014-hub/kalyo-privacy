# Kalyo — Privacy Policy

Static privacy policy for the Kalyo nutrition tracking app.

## Files
- `index.html` — English version (default)
- `privacy-fr.html` — French version

## Hosting
This repo is served via GitHub Pages at:
`https://jaguar2014-hub.github.io/kalyo-privacy/`

After enabling Pages in repo settings → Pages → Source: "Deploy from a branch" → branch: `main` → `/ (root)`, both URLs become:
- English: `https://jaguar2014-hub.github.io/kalyo-privacy/`
- French: `https://jaguar2014-hub.github.io/kalyo-privacy/privacy-fr.html`

Used in Google Play Console → App content → Privacy policy URL.
